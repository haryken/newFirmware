—battery

Audio test

Mic level is live from the robot. “Record 3 s” captures the robot mic and opens it as a WAV in a new tab.

Motion

Plays the stock .mot files from /spiffs/mot on the four leg servos. Walk and turn frames run the stock gait oscillator; frames of other stock generators are held (shown as "gait frames").

Robot controls

Every K210 command from uart_commands.md, sent as-is over UART1. Fields next to a button are the parameters (number or text); the reply shows the exact bytes sent and whether the K210 ACKed. Same thing over HTTP: POST /api/controls {"action":"anim_stay_wink_1"}.

Configuration

Wi-Fi changes apply at the next boot; the voice server address applies at the next utterance. Server → robot playback: POST http://<robot-ip>/api/play_pcm with raw 48 kHz mono int16 LE.

Power

Drops the power-enable pin: the whole robot switches off, like holding the button. On the charger it may stay powered.
